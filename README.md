## ⚡ Interactive Features
1. **Dynamic Quote Engine (`js/calculator.js`)**: Calculates realistic estimates in Sri Lankan Rupees (Rs. / LKR) based on paper stock, finishes, quantities, and turnaround speed. One click automatically formats and pre-fills a complete order inquiry into WhatsApp!
2. **Interactive Drag-and-Drop Uploader (`js/main.js`)**: Real-time pre-flight file inspection for file format extensions and 100MB limit with instant visual badges.
3. **Responsive Sticky Navigation**: Includes brand emblem, contact hotline, quick quote CTA, and animated mobile slide-over drawer.
4. **Floating Quick Actions**: One-click WhatsApp chat button with animated pulse, click-to-call button, and back-to-top button.
5. **Interactive FAQ Search**: Filters question panels in real-time as the user types keywords.
6. **Portfolio Category Filtering**: Smooth tab transitions across all 6 requested business categories.
